# โปรแกรมแก้ระบบสมการเชิงเส้น (Linear System Solver)

โปรแกรมนี้พัฒนาด้วยภาษา Python บน Jupyter Notebook  
ใช้สำหรับแก้ระบบสมการเชิงเส้น
---

## วิธีที่รองรับในโปรแกรม
1. Gauss Elimination with Partial Pivoting
2. Gauss–Jordan Elimination
3. LU Factorization
4. Inverse Matrix Method

โปรแกรมสามารถตรวจสอบได้ว่า
- ระบบสมการมีคำตอบเดียว (Unique Solution)
- ระบบสมการไม่มีคำตอบ (No Solution)
- ระบบสมการมีคำตอบไม่สิ้นสุด (Infinite Solutions)

---

## โปรแกรมสามารถทำอะไรได้บ้าง
- รับ Matrix A จากผู้ใช้
- รับ vector b (ถ้ามี)
- แสดงคำตอบ x จาก Ax = b
- แสดง Inverse Matrix (A⁻¹)
- แสดงค่า x จากสูตร x = A⁻¹b (ถ้า Inverse หาได้)
- แจ้งเตือนกรณี Matrix เป็น Singular หรือไม่สามารถหาคำตอบได้

### 2. เมนูหลักของโปรแกรม
เมื่อรัน cell เมนูหลัก โปรแกรมจะแสดง

0. จบการทำงาน

- พิมพ์ `0` เพื่อจบการทำงานของโปรแกรม

### 3. การกรอกข้อมูล Matrix A
เมื่อเลือกกรอกสมการใหม่ โปรแกรมจะถาม

กรอกขนาดของ Matrix A (n x n):

- กรอกค่า n เช่น `3` (สำหรับ Matrix 3×3)

จากนั้นกรอกค่า Matrix A ทีละแถว  
โดยตัวเลขในแต่ละแถวคั่นด้วยช่องว่าง

ตัวอย่าง Matrix A ขนาด 3×3

2 1 1  
1 3 2  
1 0 0  

---

### 4. การเลือก vector b
โปรแกรมจะถาม

Matrix นี้มี vector b หรือไม่ (y/n):

- พิมพ์ `y` ถ้ามี vector b (ต้องการแก้ Ax = b)
- พิมพ์ `n` ถ้าไม่มี vector b (ต้องการหา Inverse Matrix อย่างเดียว)

---

### 5. การกรอก vector b (กรณีเลือก y)
กรอก vector b ใน 1 บรรทัด  
โดยตัวเลขคั่นด้วยช่องว่าง

ตัวอย่าง

4 5 6
